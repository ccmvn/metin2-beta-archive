# Metin2 Chinese clients, 2004 and 2005

Three Chinese Metin2 clients from 2004 and 2005.

I started searching for early Metin2 clients about ten years ago. Since someone else has now found one of the CDs too, I am sharing all three previously unreleased Chinese clients from my private collection with my own ISO images.

## What is included

Each version has its own folder, dated from the included `metin2.bin`:

```
Metin2_2004-10-08/
Metin2_2004-11-04/
Metin2_2005-03-06/
    Client/
    Installer/
    CD/
        ISO/
        Contents/
        Photo.png
```

`Client` contains the extracted client. `Installer` contains its original installer. `CD` brings together the complete ISO, its full contents and the CD photograph.

The early client includes guild buildings and effects, the earlier skill window and the Warrior's first armour with its beta texture. The guild system shown in the [early trailer](https://www.youtube.com/watch?v=JDCJr9g3mLk) gave bonuses and had different building levels. Monsters and bosses could spawn from the buildings.

The 倚天II disc also includes `倚天II_672_468_chinajoy.avi`, the already known beta trailer at 672 × 468 pixels. This is the highest-resolution copy we have found so far. Additional scenes from 01:06 show skills from the first beta. [Watch the CD trailer](https://youtu.be/rif6fyBQuDI).

The November client preserves an early copy of SoundArranger, with 23 C++ source files in `effect.eix / effect.epk`, under `ymir work/effect/test/20`. It previews models and animations and arranges their sounds.

## Download

Large files in the repository use Git LFS. For a full clone, install Git LFS first, clone this repository and run `git lfs pull`.

The PDF covers the CD contents and menus, beta history, magazines, buildings and effects.
